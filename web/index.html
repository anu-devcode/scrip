BEFORE YOU DOWNLOAD

Clear answers.

Do I need Python or a terminal?

No. Download the Windows setup file, run it, and open Scrip from the Start menu. The installer includes Python and Qt and installs for your user account.

Does Scrip approve every request?

No. In Rules mode, only future calls matching a rule you explicitly saved can be approved automatically. Other requests remain subject to native review. Questions always require your answer in the agent.

Where does my agent data go?

Requests, rules, and history stay on your computer. The website distributes the application; it does not receive your agent events. No Scrip account or model API key is required.

Is the Windows installer signed?

This release is unsigned. Windows may show an unknown-publisher warning. Publisher signing and signed updates are not yet available. Download from this site and use the published checksum to verify file integrity.

Does this include mobile or remote control?

No. This release is a local desktop companion. Mobile access, remote agent control, additional host connections, and product deployment automation remain future work.
