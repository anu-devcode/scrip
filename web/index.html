Start and stop Antigravity command approvals from your terminal.

Download for Windows

Windows x64 · v__SCRIP_VERSION__ · Unsigned installer

  1. Install Scrip with the PATH option selected, then restart your editor.
  2. Open a terminal in your project folder. Set up the project once. 
    scrip setup --apply
  3. Start approvals when you need them. Stop when finished. 
    scrip start
    scrip stop

For Antigravity shell commands in one conversation, for up to 24 hours. Questions and native permission rules still apply.
