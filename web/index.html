Revoke future Scrip approvals. Already-running commands continue. Authorization also expires after 24 hours.

BEFORE YOU BEGIN

A few good
questions.

How is this different from Turbo?

Scrip gives you a project-terminal start/stop lifecycle bound to one conversation. It uses Antigravity’s documented hooks and still honors native Ask/Deny rules. If Turbo already meets your needs, you may not need Scrip.

Can it answer the agent’s questions?

No. Session command approval covers shell execution only. Questions still need your answer in the agent.

Can I limit it to specific commands?

Yes. Configure exact commands during setup and run scrip start --exact. The default scrip start authorizes commands throughout one conversation.

Does my code go to a Scrip cloud?

No. Scrip stores its authorization and event history on your computer. This website serves product pages and downloads. Your agent and hosting providers retain their own data practices.
