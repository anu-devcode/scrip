BEFORE YOU START

An honest
early preview.

Is this a hosted agent-control service?

No. The public site distributes Scrip and its guides. The application service binds to loopback on your own machine. It is not a public, multi-user API or a bridge to arbitrary remote agents.

What do I need to run it?

Python 3.12 or newer for the core, or Python 3.12–3.15 for the optional Qt desktop. Start in a fresh virtual environment. A graphical session is required for the desktop; Linux may need Qt system libraries.

Does Scrip automatically answer questions?

No. Questions require your response in the originating agent. Local dismissal only acknowledges the inbox item. Exact execution rules and user questions are separate.

Does it work with Codex, Cursor, or every IDE?

Not yet. The current adapters target Antigravity and Claude Code documented hook protocols. Other hosts, mobile access, shipping automation, and token optimization are future work. The underlying model alone does not establish host compatibility.

Is this ready for production use?

This is a developer alpha. Native alert behavior and live host versions are not certified. Use an isolated test workspace, review any rule or host configuration, and back up private state before upgrading.
