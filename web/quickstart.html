01

Create an isolated environment.

Choose your platform. These commands create a new environment, install the versioned download with its checksum, and start a fictional-request demo. 

python -m venv .scrip-env
.scrip-env\Scripts\python.exe -m pip install "scrip-companion[desktop] @ DOWNLOAD_URL"
.scrip-env\Scripts\scrip.exe desktop --demo

On Linux, install the Qt runtime dependencies if needed, including your distribution’s EGL library. In a headless environment, omit the desktop extra and use the CLI.

02

Explore the local inbox.

The demo shows a fictional question and tool request. No proposed tool command executes and no agent is connected. Quit Scrip to remove the demo’s temporary state; closing the window may keep it in the tray.

Read full request details, try local dismissal, pause/resume, and inspect the sessions tab. The desktop submits generic alerts where the OS supports them; actual OS display and live host versions still need certification.

03

Set up deliberate local state.

Use the scrip executable inside your environment. First initialize and start the local service: 

scrip --data-dir .scrip-dev init --port 18765
scrip --data-dir .scrip-dev serve --port 18765

Leave that terminal running. In another terminal, with the same environment and working directory: 

scrip --data-dir .scrip-dev desktop
scrip --data-dir .scrip-dev status

The service listens on 127.0.0.1. Do not expose it through a public reverse proxy or open its port to the internet. Local state can contain private arguments and questions.

04

Review an adapter before connecting it.

Generate proposed configuration without installing anything:

scrip --data-dir .scrip-dev adapter capabilities --adapter claude-code
scrip --data-dir .scrip-dev adapter config --adapter claude-code
scrip --data-dir .scrip-dev adapter config --adapter antigravity

Generators default to observation. Review the output against the host’s current documentation, then test in an isolated workspace. Configuration is never installed implicitly. Use explicit --mode enforce only after reviewing native behavior and your exact rules.

What this alpha does—and what follows.

Exact scoped policies, pending-input records, session/history views, and the Qt inbox are implemented. Unknown enforcing requests require native review; questions stay in the originating agent. A duplicate automatic approval returns to review.

Native installers, signed updates, live host certification, delivery diagnostics, retention controls, additional hosts, shipping automation, token optimization, and mobile access remain future work. This download does not establish universal host compatibility.

For this early alpha, use the private project channel through which you were invited for feedback. A public support/disclosure channel is still being established. Do not send tokens, private questions, or unredacted state files.

↶

Remove or upgrade deliberately.

Quit the desktop and stop the local service with Ctrl+C. Remove any host hook entries you explicitly added. Uninstall the package from its virtual environment with python -m pip uninstall scrip-companion.

Private state is kept separately and is not removed by uninstall. Back it up before an upgrade. Database migrations are forward-only; there is no automatic downgrade. To try another alpha, create a separate environment and test directory first.
