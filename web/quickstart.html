01

Install and open Scrip.

Open the downloaded setup file and follow the installer. Scrip installs for your user account and adds a Start menu shortcut. Open Scrip when installation finishes.

The app starts its private local connection automatically. You do not need to install Python, create an environment, start a service, or keep a terminal open. No sample sessions or questions are added.

02

Connect a Claude Code workspace.

In Connections, choose Connect Claude Code workspace and select your project folder. Choose Notifications mode for visibility with native permissions unchanged, or Rules mode to use exact approval rules.

Review the configuration, then choose Connect workspace. Scrip adds its documented hooks to that project's Claude Code settings, preserves other settings, and makes a backup. Connection setup never changes IDE application files.

Start a new Claude Code session in the project so the host loads the hooks. "Configured" means the configuration is present; the Sessions tab shows activity only after real events arrive.

03

Work from your inbox.

Keep Scrip open or in its tray. Structured questions and approval requests appear with their full details. Answer questions and resolve current permission prompts in Claude Code. Dismiss locally clears an inbox item without sending an answer.

In Rules mode, select a pending approval request and choose Create exact approval rule. Review the tool and complete arguments before saving. The rule applies to future exact matches in that workspace and expires after 24 hours. It does not approve the current native prompt. Pause rules from the toolbar or remove them from the Rules tab.

04

Stay connected on your terms.

Closing the window keeps Scrip in its tray when a tray is available. Choose Quit to stop its local connection. Host permissions remain with the agent when Scrip is unavailable.

Use Connections to disconnect a workspace before uninstalling. This removes Scrip's saved hook entries while preserving other hooks and settings. Uninstall from Windows Settings → Apps. Private Scrip history is retained separately under your user profile.

Current availability

The installable build is Windows x64 with a guided Claude Code workspace connection. You still need Claude Code and an active session. Other agents, native macOS/Linux installers, mobile, and remote controls are not included. Live host-version and OS-notification certification are still in progress.

If no events appear, check the workspace connection status, restart the agent session, and confirm Scrip is running. Managed host settings can disable hooks. Do not disable your host's protections to force a connection.

Updates are downloaded and installed manually. There is no silent updater. For developers, the Python package is also available; it is not required by the Windows installer.
