Current · __SCRIP_VERSION__November 2026

Command approval for the conversation.

The default scrip start now covers all shell commands in one Antigravity conversation. Stop with scrip stop. No command-by-command list is required.

  • Conversation binding happens atomically on the first valid command after start.
  • A second conversation or project cannot inherit that authorization.
  • Repeated starts preserve an active binding. Stop/start explicitly arms a new conversation.
  • The live callback’s top-level cwd is now accepted and validated.
  • Questions and native Ask/Deny rules remain with the host.
  • The optional exact-command mode remains available with --exact.

The standalone Windows installer bundles its runtime and offers a user-PATH entry. The website distributes the terminal package; it does not require the older Scrip desktop app.
