PRIVACY

Your workspace.
Your computer.

The desktop application

Scrip stores agent events, questions, tool arguments, rules, workspace paths, and session history locally under your operating-system user profile. That information can contain private material. The current app has no telemetry, cloud sync, or Scrip accounts.

Its authenticated service listens only on your computer's IPv4 loopback interface. Your local token is not sent to this website. Host integrations send events to that local service using documented hooks.

Workspace settings

A connection changes only the selected project's documented Claude Code settings after you review and confirm it. Existing settings are backed up. Disconnect removes owned hook entries. Uninstall does not erase private history or change host settings silently.

The website

This site distributes Scrip and installation information. It has no advertising trackers, analytics scripts, sign-up forms, or application cookies. Hosting infrastructure handles network information such as IP address and request metadata to serve downloads and maintain security.

Your choices

Disconnect projects and quit Scrip to stop collecting new activity. Private state is retained on uninstall so upgrades do not erase it. Keep a backup before manually removing local state. Never publish your local database, token, or unredacted agent requests.
