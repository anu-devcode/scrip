The public website

This static site distributes the developer alpha and its guides. Scrip’s page code has no analytics, advertising scripts, account system, contact form, or tracking cookies. The hosting provider may process request and infrastructure logs according to its own policies. No agent events are submitted to this website.

The local application

Current Scrip state stays in a local SQLite database and associated files. Events can contain tool arguments, workspace paths, and questions. The API token is a local credential, not a model-provider key. Scrip does not encrypt this state; protect the data directory and the OS account that owns it.

The current policy engine makes no model call. Your originating agent, IDE, model provider, and other tools have their own data behavior; using Scrip does not change their policies.

Notifications and sharing

The desktop sends generic alert titles to the OS notification backend. Full request details remain in the local inbox. The current app does not forward answers, add telemetry, upload state, or connect to a remote synchronization service.

Only share deliberately redacted diagnostics through the project’s private alpha feedback channel. Do not publish tokens, database files, or private question/command content.

Removal

Uninstalling the package does not delete local state. Quit the desktop, stop the service, remove any host entries you added, and manage the data directory you selected. Back up any history you want to retain before deleting that directory.

These notes describe this alpha’s implemented behavior. They are not a claim of security certification or a replacement for an eventual supported-release privacy policy.
