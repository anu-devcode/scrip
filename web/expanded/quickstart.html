02 / CONNECT ONCE

Review your project hook.

Open a terminal in the project root used by your Antigravity conversation. Preview the complete proposed configuration:

PowerShell 
scrip setup

Review the named Scrip entry. To approve saving it to that project’s .agents/hooks.json, run:

PowerShell 
scrip setup --apply

Setup preserves other hooks, makes a backup of existing settings, and leaves approvals stopped. Begin a new agent turn so Antigravity loads the hook. Existing approval prompts still need a response in the host.

03 / YOUR DAILY CONTROLS

Start. Work. Stop.

PowerShell 
scrip start

The first valid shell-command callback binds approval to one conversation. All shell commands in that conversation are authorized until you stop or 24 hours pass. This includes writes, deletion, publishing, and network use.

PowerShell 
scrip status --project

Check whether authorization is active, which conversation it is bound to, and when it expires. “Active” alone does not prove that the agent has delivered an event.

PowerShell 
scrip stop

Future Scrip approvals stop immediately. Running commands and approvals already returned cannot be recalled. To switch conversations, stop, then start before continuing the intended conversation. Starting again while active preserves the existing binding.

Questions still need your answer. Native Ask/Deny rules still apply. This authorization is not an OS sandbox.

OPTIONAL / EXACT MODE

Prefer a command list?

Review and apply setup with the exact commands you want:

PowerShell 
scrip setup --allow-command 'git status' --apply
PowerShell 
scrip start --exact

Repeat --allow-command to configure additional exact commands. A different command or working directory won’t receive exact-mode approval. The default scrip start continues to select conversation mode.

MAINTENANCE

Update or remove Scrip.

Install a new version over Scrip Terminal to update. There is no silent updater. Existing project setup and private history are preserved.

Before uninstalling, run scrip stop in each configured project. Remove only scrip-project-commands through Antigravity’s documented hook settings, preserving your other hooks. Uninstall Scrip Terminal from Windows Settings → Apps.

Private state remains under %LOCALAPPDATA%\Scrip\projects. Back up anything you need before manually removing it.
