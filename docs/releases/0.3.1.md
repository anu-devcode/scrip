# 0.3.1 — diagnostic update, local installation

Adds a last-callback diagnostic to `scrip status --project`. It records processing stage,
exception type, callback field names/types, workspace count, and decision category. It does
not retain raw callback data, command values, paths from the payload, transcript text, or
exception messages. Diagnostic-write failure does not change the permission decision.

The live Antigravity call reported "Scrip unavailable" before recording an event. The
underlying callback failure is not yet identified. This update preserves exact command
authorization, 24-hour expiry, revocation, and the existing review-on-error fallback. It does
not represent live-host certification or a claim that the reported failure is resolved.

No project setup or authorization needs to be recreated to receive the diagnostic. A new
callback from the live agent is required; the earlier process did not persist its input.
