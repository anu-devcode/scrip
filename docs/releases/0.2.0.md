# Scrip 0.2.0

Windows x64 setup now includes Python and Qt and adds a Start menu shortcut. Opening Scrip
initializes empty private state and starts its local service automatically. No terminal setup,
seeded sessions, demo mode, or sample requests are included.

The Connections screen guides explicit Claude Code workspace setup with settings review,
backups, preservation of existing hooks, and a disconnect action. The Inbox can propose an
exact 24-hour approval rule from an actual pending tool request. Rules can be paused or removed.
Existing native prompts and questions must still be resolved in the host.

The public Azure site distributes the versioned installer and checksums at scrip.anwardev.me.
The installer is unsigned. Live host-version/native OS notification certification, signed
updates, other native platforms and guided hosts, mobile, and remote control remain outstanding.
