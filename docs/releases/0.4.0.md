`scrip start` now authorizes all shell commands in one Antigravity conversation, within the
configured workspace, until `scrip stop` or the existing 24-hour expiry. It binds atomically
to the first valid command callback after start. Other conversations cannot reuse that grant.
Repeated starts preserve an existing conversation binding; stop followed by start explicitly
arms a new binding. Native Ask/Deny rules and Scrip exact deny rules still apply. Questions,
MCP tools, browser actions, and unrelated tool types are not granted command approval.

Session mode includes deletion, writes, publishing, and network use; working-directory
scope is not OS isolation. Exact command lists remain available through `scrip start --exact`.
New projects can review `scrip setup`, explicitly install with `scrip setup --apply`, then start.
Existing configured projects need only the updated binary and `scrip start`.

Fixes the observed live callback shape: Antigravity supplies `cwd` at the top level rather
than `toolCall.args.Cwd`. Scrip accepts that absolute path, checks it against an argument-level
directory when both exist, and rejects discrepancies and out-of-workspace directories. The
display-only `toolSummary` is excluded from exact matching. A missing actual command directory
is still rejected rather than guessed. The field-type diagnostic provided evidence for this fix.

Tests cover concurrent binding, different commands within a conversation, another conversation,
workspace separation, expiry, pause, explicit deny, replay, revocation, and the observed callback
shape. The bundled executable is exercised through cmd and PowerShell using temporary settings
and inert command strings. These checks never run the proposed commands or modify installed IDEs.
Live-host success still requires a subsequent real callback. The installer remains unsigned.

## Distribution and website

A dedicated per-user Scrip Terminal installer includes the runtime and offers a user-PATH
entry. Install/reinstall/removal checks run on a disposable Windows runner. The public site
now includes the setup guide, compatibility, privacy, security, and release pages, accessible
copy controls, and a reduced-motion alternative for the original robot mascot.
