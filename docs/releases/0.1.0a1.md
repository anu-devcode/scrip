# Scrip 0.1.0a1 — developer alpha

The first versioned preview distributes the local Python companion, CLI, and optional Qt
desktop inbox. It includes exact scoped permission rules, session/event history, structured
input records, pause/resume, a notification outbox, and documented-hook adapter protocols.

Start with `scrip desktop --demo` in a fresh Python environment with the desktop extra.
The demo uses temporary fictional requests, never executes proposed tools, and does not
modify an IDE. Answer real questions in the originating agent; local dismissal only clears
the inbox item. The application API remains on loopback.

This is a developer alpha, not a production-ready or universally compatible agent product.
The current adapter protocols target Antigravity and Claude Code. Live host versions and
native OS alert display are not certified. Cursor, Codex, shipping automation, token
optimization, mobile access, native installers, and signed updates are not included.

The wheel is a Python package, not a one-click installer. The core requires Python 3.12+;
the optional desktop requires Python 3.12–3.15 and a graphical session. Linux needs Qt's
system libraries. Back up private state before upgrades; database migrations are forward-only.

Artifacts include the wheel, source archive, static website/download bundle, and SHA-256
checksums for the wheel and web bundle. Source archives and GitHub releases retain the
repository's access controls; the public download site serves the wheel and public guides.
No API tokens, runtime databases, private SSH keys, or IDE patching tools are included.
