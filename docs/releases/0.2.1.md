# Scrip 0.2.1

Alerts now shows recent notification delivery state, cumulative attempts, and sanitized
failure types. A failed alert about a pending question or approval request can be explicitly
queued again. Resolved, expired, and locally dismissed requests cannot be revived by retry;
already sent alerts cannot be replayed manually. Retrying never executes a tool or
answers a question.

The desktop distinguishes a sent notification from confirmed display or reading. Windows
notification settings can still suppress alerts. Startup remains empty and workspace settings
are changed only through the existing explicit Connections review.

The installer remains unsigned. Live host-version/native notification certification,
retention controls, other guided hosts/platforms, and mobile remain outstanding.
