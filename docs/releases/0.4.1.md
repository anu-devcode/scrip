# 0.4.1 — concise terminal feedback

- `scrip setup --apply` prints `Scrip setup complete.` after successful setup.
- `scrip start` prints `Scrip started.` after successful activation.
- `scrip stop` prints `Scrip stopped.` after revoking future approvals.
- `scrip setup` retains the explicit configuration preview. `scrip status --project`
  retains its structured scope, binding, expiry and diagnostic details.
- The minimal download page adds a Copy button for each setup, start and stop command,
  with keyboard support and clipboard success/failure feedback.

The installer remains unsigned while the signing application awaits provider review.
