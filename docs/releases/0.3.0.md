# 0.3.0 — local build, not yet published

Adds one-time reviewed Antigravity project setup and daemon-free `scrip start` / `scrip stop`.
Exact commands are scoped to the project root, expire after 24 hours, and preserve native
Ask/Deny rules. Setup defaults to a complete preview; only explicit `--apply` installs hooks.
`scrip status --project` reports local authorization. Questions remain with the host.

Scrip Terminal is a separate console-only Windows installer with a real `scrip.exe`, a
`scrip-cli.exe` hook entry point, and a bundled Python runtime. It requires no Qt and does
not replace the installed Scrip desktop app. The terminal installer offers a user PATH entry
and removes only an entry it added itself. Existing project settings and private state
remain after uninstall.

The development tree also retains the previously implemented Cursor guided connection,
single-transaction desktop snapshot, static S logo, and animated robot mascot. The terminal
installer does not bundle those desktop/web features. A native Qt import failure blocked the
combined desktop build on this machine; it is not released as a working v0.3.0 desktop build.

This file describes the local build. It does not indicate a GitHub/Azure release or live
Antigravity certification. The installer is unsigned.
